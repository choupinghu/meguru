# Reference images — provenance

These are **not** photographs of the items in this collection. Each is a photograph of another
copy of the same *design*, sourced from a public listing and background-removed, used as the
design-level premier image (the map). The owner's own photograph of the actual item is what
appears on the item record — see CLAUDE.md invariant 3.

Twelve of the twenty-five owned designs are blister-packed, and Kitty cannot be isolated from
behind the plastic; those keep the generated `CharmArt` placeholder instead.

Copyright in each source photograph remains with whoever took it. This repository is private.
If any rights holder objects, delete the file and its row below.
